# Meridian Financial: customer package

This folder is the cold start for the capstone. There is no mission text here that
tells you the answer.

Read `00-inbox/` first, then `12-history/prior-vendor-postmortem.md` before you
build anything. The prior vendor already paid for a lesson. Spend their money,
not yours.

Files marked `.md` that look like `.pdf` or `.xlsx` are text stand-ins for binary
artifacts. Treat them as the real thing.

When a path is thin, that is intentional. Real packages have holes. Your job is
to notice what is missing and ask for it, or prove you do not need it.
