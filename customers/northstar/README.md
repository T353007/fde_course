# Northstar Capital: your working folder

This directory is **your** deliverables for the Northstar engagement. It is not part
of the lab services; nothing in Docker reads these files.

Mission 01 asks you to save `engagement-brief.md` here. Mission 02 adds
`system-observations.md`. Later missions add notes, maps, and eval artifacts under this
tree.

If the folder did not exist yet, create it:

```bash
mkdir -p customers/northstar/notes customers/northstar/checks
```

Do not commit secrets, API keys, or customer PII you invent for exercises. Markdown
and small scripts are fine.
